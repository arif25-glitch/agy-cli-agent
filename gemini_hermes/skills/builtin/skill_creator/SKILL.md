# Skill Creator Procedure

When you solve a novel problem, execute a complex multi-step pipeline, or discover a repeatable technique:
1. Identify the core procedural steps that made the solution successful.
2. Formulate a clean, reusable specification following the `agentskills.io` standard:
   - Provide a clear `name` (lowercase, alphanumeric with dashes/underscores).
   - Provide a concise `description` of when to use this procedure.
   - Specify step-by-step instructions, parameters, common pitfalls, and examples.
3. Save the new skill by instructing the user or using the skill persistence method so it will be available in future sessions.
